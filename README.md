# Probability-models
This repository contains computational exercises and simulations in probability and stochastic processes.

The project covers
Monte Carlo simulation and estimation
Importance sampling
Markov Chain Monte Carlo 
Gibbs sampling
The 2D Ising model
Single-server queueing models
Brownian motion and random walks

The simulations are implemented primarily in Python using NumPy, Matplotlib, and Pandas, and are presented in a single Jupyter Notebook.
The notebook includes the relevant mathematical formulas and explanations, together with the Python code used for the computations and simulations.
